## RAPID Quick Start Guide
RAPID is a programming language that ABB gives their customers to program their robots. It is a high level language and you will generally not have detailed control over path planning or trajectory planning. If you use the MoveL command, RAPID also does not avoid singularities so it is possible to lock the robot arm this way. If you would like to control the robot joints through an external program you can use ABB's Externally Guided Motion (EGM) and set it up ***inside RAPID.***
