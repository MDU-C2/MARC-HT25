## System failure

When you start the robot you will most likely get the error "SMB communication failure" on the FlexPendant (the wired controller) and a system failure. System failure will prevent you from doing most things with the robot. To get out of this you will need to go to Restart -> advanced -> revert to last auto saved. The controller will restart and you will have to calibrate the right arm.
